## How to install

1. Download the folder of the skill or pack you want from this repository.
2. Copy each skill folder into `~/.claude/skills/` to use it everywhere, or into `.claude/skills/` inside one project. For Codex, use `~/.agents/skills/`.
3. Open Claude Code and describe the task. Claude picks up the skill on its own, or you can call it by name (for example `/financial-snapshot`).
